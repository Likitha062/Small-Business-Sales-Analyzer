# Small Business Sales & Profit Analyzer

This project is developed as part of the Infosys Springboard Virtual Internship 6.0.

## 📌 Project Overview
The Small Business Sales & Profit Analyzer is an AI-based system designed to help small businesses manage and analyze their financial data. It allows users to track sales, expenses, and inventory, while providing insights through dashboards and forecasting future trends using machine learning.

## 🚀 Features
- User Authentication (Login & Register)
- Business Management (Multiple businesses per user)
- Sales Tracking
- Expense Management
- Inventory Management with COGS
- Profit Calculation (Revenue - Expenses - COGS)
- Interactive Dashboard (Charts & Insights)
- AI Forecasting (Linear Regression & Prophet)
- Report Generation (Excel & PDF)
- Admin Dashboard

## 🛠 Technologies Used
- Python
- Streamlit
- SQLite
- Pandas & NumPy
- Plotly
- Scikit-learn
- Prophet

## 📊 Modules
1. Authentication Module  
2. Sales & Expense Tracking  
3. Inventory Management  
4. Analytics Dashboard  
5. Forecasting Module  
6. Report Generation  
7. Admin Dashboard  

## 📁 How to Run
1. Install required libraries:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py
